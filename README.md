# 📚 StudyBuddy

StudyBuddy is a simple and user-friendly study website designed to help students organize and manage their study routine.

## ✨ Features

* 📖 Simple and clean study interface
* 📝 Easy-to-use layout
* 📱 Responsive design
* 🎨 Student-friendly UI
* 🌐 Hosted using GitHub Pages

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🌐 Live Demo

[Visit StudyBuddy](https://bhoomi29-a.github.io/StudyBuddy/)

## 📂 Project Structure

```text
StudyBuddy/
│
├── index.html
├── style.css
└── style.js
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start using StudyBuddy.

## 🎯 Purpose

This project was created to practice front-end web development and build a practical student-focused website.
